Conclusion: the four B300s are not fully utilized. Only three participate in 1P/2D, GPU 3 is blocked by a foreign process, and average compute utilization on active GPUs remains well below saturation. ≈245 GiB allocated per worker is mostly model plus reserved KV cache—not sustained compute. The concurrency wedge is the current limiter.

Reproducible concurrency availability incident

Sharp boundary: 1P/2D c6 passes and c7 wedges; two aggregate replicas pass c12, partially fail c14, and fully wedge at c16. After cancellation, discovery remains healthy but new c1 requests hang. A process restart is required.
FactInterpretation
c1/c2/c4 pass on the same deployment.Endpoint, tokenizer, client, and basic disaggregation are sound.
c8 failed at 300 s on job 7967 and 120 s on fresh job 7975.Slurm expiry is ruled out as the primary cause.
All eight errors land at the timeout boundary with no response bytes.Failure is inside serving/scheduling before streaming output.
Green health persists while requests hang.Discovery liveness is not application readiness.

Current interpretation: a per-engine concurrent-prefill threshold around seven is implicated. NIXL/disaggregation makes the global threshold lower because requests converge on one prefill engine, but NIXL is not necessary: aggregate c14/c16 also fail. Prefix caching is not primary because prefix-off c16 reproduces. The exact hybrid-cache, scheduler, or kernel root cause remains unproven.

Slurm restart runbook

Weights and the Enroot squashfs live on shared storage. A new allocation needs node-local state and kernel autotuning, not another download.

srun \
  --account=tech_team \
  --partition=maint \
  --qos=tech_team \
  --nodes=1 \
  --ntasks=1 \
  --cpus-per-task=128 \
  --mem=1024G \
  --gres=gpu:b300:4 \
  --time=08:00:00 \
  --pty bash -l

module load rootless-docker
cd /home/yagupta/experiments/inf_exps
./scripts/bootstrap-slurm.sh

The bootstrap records job/node/resources and GPU/runtime state, handles stale PIDs, requires one prefill plus two decoder registrations, then validates API, tool calling, and Pi. Evidence is stored under artifacts/restarts/.

Cached startup still takes several minutes: three weight loads, graph compilation, hybrid KV registration, UCX initialization, and 21-profile FlashInfer MoE autotuning. Persisting safe compilation/autotuning caches is a future experiment.

Operational lessons

Lifecycle
Persist data, not processes

Slurm kills process trees. Shared weights, image, scripts, and manifests make recovery routine.

Health
Probe the data plane

Green discovery can coexist with zero decoders or a wedged request path.

CPU
128 cores fixed starvation

GPU health says little about etcd, download, tokenization, routing, and Pi.

Runtime
Mount namespaces matter

Rootless privileged mode could not reveal sysfs; UCX needed host integration.

Benchmarks
Failed runs are data

c8 has no throughput result, but its failure/recovery behavior is valuable.

Secrets
Keep tokens out of traces

A diagnostic exposed an inherited HF token in a private transcript; rotation was required.
